Muse invite code FAQ

What is a Muse invite code?

A 6-character referral code from an existing Muse user. Redeem one within 48 hours of joining and both of you receive 1 billion Muse tokens.

Where do I enter the code?

In Muse: Settings → General → Redeem invite code. Codes are only ever entered inside the official Muse app — never on a third-party site, and never together with your password.

Do the tokens expire?

No. Invite-code tokens are additional tokens with no expiry, on top of the regular plan allowance.

Museの招待コードはいつまでに入力すればいいですか？

Museに登録してから48時間以内です。設定 → General → Redeem invite code から入力すると、双方に10億トークン（期限なし）が付与されます。

A code did not work. What now?

Codes can run out as other people redeem them. Just try the next code in the list — the bonus is the same for every valid code.
