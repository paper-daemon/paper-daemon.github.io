# 業務チェックリスト【お試し版】

印刷して使うか、タスク管理ツールに転記して使ってください。各項目の □ にチェックを入れながら進めます。

## チェックリスト1：見積→請求の抜け漏れ防止チェック

見積書を作るときと、請求書に切り替えるときの両方で使うリストです。請求漏れ・二重請求の防止が目的です。

### 見積書作成時
- [ ] 宛先（会社名・部署・担当者名）に誤りがない
- [ ] 見積日と有効期限が入っている
- [ ] 品目・数量・単価がすべて入っている
- [ ] 金額の掛け算と合計が合っている
- [ ] 税率（10%／8%／非課税）が品目ごとに正しい
- [ ] 納期・納品場所が明記されている
- [ ] 支払条件（支払期限・支払方法）が入っている
- [ ] 自社の会社情報・連絡先が入っている

### 成約後、請求書への切り替え時
- [ ] 見積書の内容と請求内容が一致している（変更点があれば理由を記録）
- [ ] 請求日と支払期限が入っている
- [ ] 請求書番号が重複していない
- [ ] 振込先情報が正しい
- [ ] 適格請求書として必要な項目（登録番号・税率ごとの金額）が揃っている
- [ ] 送付先のメールアドレス・宛名が正しい
- [ ] 送付後に送付済みとして記録した

### 月末の請求漏れ確認
- [ ] 今月の納品・対応実績をすべて洗い出した
- [ ] 実績と請求済みリストを照合した
- [ ] 未請求の項目があれば請求書を作成した
- [ ] 請求済みのはずが未入金のものを確認した
