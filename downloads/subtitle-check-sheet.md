# 字幕（SRT）納品前チェックシート【無料版】

SRT字幕ファイルを納品・読み込みする前に確認するリストです。

## タイミング
- [ ] 開始時刻と終了時刻が逆転している行がない
- [ ] 前後の字幕の時刻が重なっていない
- [ ] 表示時間が短すぎる字幕（0.5秒未満など）がない
- [ ] 動画の長さを超えた時刻の字幕がない

## テキスト
- [ ] 1行の文字数が長すぎない（目安：全角20字程度まで）
- [ ] 改行位置が文の切れ目に合っている
- [ ] 誤字脱字・表記ゆれ（送り仮名、英数字の全角半角）がない
- [ ] 話者や効果音の表記ルールが全体で統一されている

## 形式
- [ ] 文字コードがUTF-8
- [ ] 連番が1から順に振られている
- [ ] 空行区切りなど、SRTの基本形式が崩れていない
