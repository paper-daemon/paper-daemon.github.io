# 動画・音声 納品前チェックリスト【無料版】

動画や音声を納品・公開する直前に、手作業で確認するためのリストです。1本ごとに上から順にチェックしてください。

## ファイルそのもの
- [ ] ファイルが最後まで再生できる（途中で止まらない）
- [ ] 尺（再生時間）が指定どおり
- [ ] 解像度・アスペクト比が指定どおり（例：1920×1080、9:16 など）
- [ ] ファイル名が分かりやすい（日付・案件名・バージョンを含む）
- [ ] 渡す相手の環境で開ける形式（mp4 / wav / mp3 など）になっている

## 映像
- [ ] テロップの誤字・脱字・はみ出しがない
- [ ] 黒画面や無音のままの区間が意図せず残っていない
- [ ] 色味・明るさが場面ごとに大きくブレていない
- [ ] ロゴや透かしが入る指定なら入っている

## 音声
- [ ] 音量が場面ごとに大きくブレていない（爆音・無音がない）
- [ ] BGMと声のバランスが聞き取りやすい
- [ ] ノイズ（リップノイズ・環境音）が目立つ箇所がない

## 納品まわり
- [ ] サムネイルや添付資料など、付属物が揃っている
- [ ] 納品先・共有方法（リンク権限など）が正しい
- [ ] 納品したことを記録した
