A safer workflow in 3 moves
01 / RECORD

Reserve a stable event ID

Use the webhook provider's event ID, a business key, or a durable unique constraint. Do not trust the HTTP request arriving only once.

02 / RECONCILE

Check before replay

A timeout can mean "unknown." Check the remote write before retrying. A non-atomic check-then-write can race under concurrent events.

03 / VERIFY

Test the failure path

Send the same event twice, then simulate a timeout after the downstream write. Verify only one irreversible effect occurs.
